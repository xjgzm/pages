This Privacy Policy describes how the Chrome extension "YouTube Live Chat Translator" (hereinafter referred to as "this Extension") handles and transmits information.

What This Extension Does

This Extension reads comment text displayed on YouTube Live chat screens (youtube.com/live_chat and youtube.com/live_chat_replay), sends it to the configured translation engine to retrieve translated results, and displays them below the original comments.

Information Collected and Transmitted

DataDetailsDestination
Chat comment text Text content of comments displayed in the YouTube Live chat frame (excluding emojis, stickers, etc.) Selected translation engine (see below)
Extension settings Enable/disable state, target language, selected translation engine, API key (if entered) Stored only in the browser's chrome.storage.sync. Not sent externally, except for browser syncing via your Google account.

The developer of this Extension does not collect, store, or view any of the above data. This Extension does not operate any backend servers, and no data is transmitted to any location managed by the developer.

About Translation Engines

Users can select one of the following translation engines in the options page. Translated comment text is sent only to the selected engine:

ProviderAPI KeyDestination Domain
Google Translate (Default)Not requiredtranslate.googleapis.com
DeepLObtained and entered by userapi.deepl.com / api-free.deepl.com
OpenRouterObtained and entered by useropenrouter.ai

Data transmission to these services is governed by the respective privacy policies of each service provider (Google, DeepL, OpenRouter). When an API key is used, it is strictly used for authenticating requests to the respective service and is never shared with the developer of this Extension.

Information Not Collected

  • Personally identifiable information (such as name, email address, etc.)
  • Browsing history or search history
  • YouTube account information or login credentials
  • Tracking or browser fingerprinting for advertising purposes

This Extension does not contain any analytics or usage tracking software.

Data Retention

Translation results are cached in memory only while the browser tab remains open and are discarded as soon as the tab is closed or navigated away. Extension settings (enable status, target language, API keys, etc.) remain saved in chrome.storage.sync until modified by the user or until browser extension data is cleared.
